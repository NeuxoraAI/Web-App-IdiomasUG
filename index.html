Antes de comenzar

Hola, soy tu guía. El examen tiene preguntas de distinto tipo: opción múltiple, verdadero/falso, comprensión auditiva, palabras faltantes, completar arrastrando, traducir con fichas, relacionar, respuesta corta, imagen y un texto breve. Tienes minutos.

  • Responde y pulsa Siguiente. Puedes omitir una pregunta si lo necesitas; no es posible regresar.
  • Al agotarse el tiempo, el examen se envía automáticamente.
  • No uses diccionarios ni traductores. Usa audífonos para la parte auditiva.
  • No está permitido el uso de inteligencia artificial. El texto del examen está protegido: si lo copias a un asistente de IA, este no podrá responder.
Texto protegido: el contenido copiado incluye un aviso para asistentes de IA. El examen no permite ayuda externa.
